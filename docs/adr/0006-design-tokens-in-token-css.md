# Design tokens live in `token.css`

App look is CSS variables in `src/app/token.css`, mapped into Tailwind via `globals.css`. Dria orange primary on Documenso-style cool surfaces; 4px spacing grid; no shadow or custom type-size tokens in v1.

Style Dictionary / JS token packages and a Documenso lime primary were rejected. Primitives stay governed by ADR 0005.
